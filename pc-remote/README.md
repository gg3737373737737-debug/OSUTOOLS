# PC Remote — управление компьютером с телефона

Веб-приложение, которое ставится на главный экран телефона (Android и iPhone).
На компьютере работает маленький сервер на Python, без сторонних библиотек.

**Что умеет:**
- **Пульт (как Stream Deck):** сетка своих кнопок с иконками и цветами, настраивается прямо с телефона.
- **Питание:** выключить, перезагрузить, сон, блокировка, погасить экран, выход, таймер выключения и его отмена.
- **Мышь:** тачпад (тап — клик, два пальца — прокрутка, тап двумя пальцами — правый клик).
- **Клавиатура:** набор текста (русский тоже), стрелки, Enter, Esc, Alt+Tab, Alt+F4 и т.д.
- **Медиа:** громкость, пауза, следующий/предыдущий трек, открыть сайт, снимок экрана.
- **Состояние ПК:** загрузка CPU и RAM, время работы.

## Установка (Windows)

1. Установите Python с https://python.org. В установщике отметьте **Add python.exe to PATH**.
2. Скопируйте папку `pc-remote` на компьютер.
3. Запустите `start.bat`. Если Windows спросит про брандмауэр, разрешите доступ для **частных сетей**.
4. В консоли появится ссылка вида `http://192.168.1.5:8765/?t=...`. Откройте её на телефоне
   (телефон должен быть в той же Wi-Fi сети).
5. Добавьте страницу на главный экран:
   - Android (Chrome): ⋮ → «Добавить на главный экран»;
   - iPhone (Safari): «Поделиться» → «На экран Домой».
6. Чтобы сервер запускался вместе с Windows, запустите `autostart-install.bat`
   (убрать из автозагрузки можно через `autostart-remove.bat`).

Linux: `python3 server.py`. Для мыши и клавиатуры нужен `xdotool`, для звука `pactl`, для плеера `playerctl`.

Снимок экрана необязателен. Чтобы он работал, выполните `pip install pillow`.

## Пульт (Stream Deck)

Вкладка «Пульт» открывается первой. Чтобы изменить кнопки, нажмите **✎ Настроить**:
нажатие на кнопку открывает её редактор, «+» добавляет новую, ← → меняют порядок.
Кнопка «▦» меняет размер сетки (2–5 в ряд). Кнопки хранятся на компьютере в `config.json`,
поэтому одинаково выглядят на всех телефонах.

Типы действий:

| Действие | Пример значения |
|---|---|
| Сочетание клавиш | `ctrl+shift+s`, `f9`, `alt+f10`; несколько шагов через запятую: `ctrl+a, ctrl+c` |
| Запустить программу / файл | `C:\Program Files\obs-studio\bin\64bit\obs64.exe`, `notepad`, `calc` |
| Открыть сайт | `twitch.tv` |
| Напечатать текст | `Всем привет!\n` (`\n` нажимает Enter) |
| Команда (cmd) | `start steam://rungameid/730` |
| Питание | выключить, сон, блокировка… |

**Для стрима в OBS:** в OBS → Настройки → Горячие клавиши назначьте, например, `ctrl+alt+f1`
на «Начать запись» или «Сцена 1». Затем создайте кнопку с таким же сочетанием.
Работает, даже когда OBS свёрнут.

## Включение компьютера (Wake-on-LAN)

Выключенный компьютер не может принять команду, поэтому его будит «магический пакет».

1. В BIOS/UEFI включите **Wake on LAN** (может называться «Power On by PCI-E/PCI»).
2. В Windows откройте Диспетчер устройств → сетевая карта → Свойства:
   - вкладка «Дополнительно»: **Wake on Magic Packet = Enabled**;
   - вкладка «Управление электропитанием»: отметьте «Разрешить этому устройству выводить компьютер из ждущего режима».
3. Отключите быстрый запуск: Панель управления → Электропитание → Действия кнопок питания → снимите «Включить быстрый запуск».
4. Компьютер должен быть подключён **кабелем**.
5. MAC-адрес показан в приложении (вкладка «Питание») и в консоли сервера.
   **Проверьте его**: выполните `ipconfig /all` и найдите «Физический адрес» проводного адаптера.
6. Чтобы включить ПК, используйте одно из:
   - приложение **Wake On Lan** из Google Play или App Store;
   - функцию WoL в роутере (Keenetic, ASUS, MikroTik и др.);
   - `wol.py` на любом включённом устройстве: `python wol.py AA:BB:CC:DD:EE:FF`
     (на Android можно через приложение Termux).

## Управление не из дома

Установите **Tailscale** (бесплатно) на компьютер и телефон и войдите в один аккаунт.
Открывайте приложение по Tailscale-адресу компьютера (`100.x.x.x:8765/?t=...`).
Открывать порты на роутере **не нужно и не рекомендуется**.

## Безопасность

- Доступ защищён случайным ключом, он хранится в `config.json` рядом с сервером.
  Не показывайте ссылку с ключом посторонним.
- Чтобы сменить ключ, удалите `config.json` и перезапустите сервер.
- В `config.json` можно поменять порт (`"port": 8765`).
